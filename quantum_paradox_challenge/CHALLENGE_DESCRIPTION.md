# Quantum Paradox Challenge

## 🚀 **Descripción del Reto**

Bienvenidos al **Quantum Paradox Challenge**, un reto de reverse engineering de dificultad **INSANE** que pondrá a prueba vuestras habilidades más avanzadas.

### 📋 **Información General**
- **Dificultad**: INSANE
- **Tipo**: Reverse Engineering
- **Tiempo estimado**: 2+ horas
- **Herramientas recomendadas**: IDA Pro, Ghidra, GDB, editor hexadecimal

### 🎯 **Objetivo**
Vuestro objetivo es encontrar la flag real oculta en el binario. El formato de la flag es `HTB{...}`.

### ⚠️ **Advertencias Importantes**
- Este reto contiene **múltiples flags falsas** diseñadas para confundiros
- Solo hay **UNA flag real** - las demás son señuelos
- El reto tiene **protecciones anti-debugging** activas
- Se requiere **análisis de memoria** para resolverlo completamente

### 🔧 **Características del Reto**
- Binario de 1.9MB con múltiples capas de ofuscación
- Protecciones anti-debugging implementadas
- Código ofuscado con técnicas avanzadas
- Múltiples rutas de ejecución y funciones
- Datos falsos y señuelos estratégicamente colocados

### 🎮 **Instrucciones**
1. Descargad el archivo del reto
2. Extraed el contenido del archivo comprimido
3. Leed la documentación incluida
4. Analizad el binario principal
5. Encontrad la flag real (no las falsas)

### 💡 **Consejos Generales**
- No os confiéis de las primeras flags que encontréis
- El análisis estático es crucial
- La flag real está oculta de manera muy específica
- Pensad como un reverser experimentado

### 🏆 **Recompensa**
La satisfacción de haber resuelto uno de los retos de reversing más desafiantes, diseñado específicamente para poner a prueba vuestras habilidades más avanzadas.
